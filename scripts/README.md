


INVOICE SYSTEM INSTALLATION GUIDE
==================================

REQUIREMENTS:
- Windows 10/11 (64-bit)
- 8GB RAM minimum
- Internet connection (first-time setup)

INSTALLATION:
1. Install Docker Desktop for Windows from docker.com
2. Run setup.bat as Administrator
3. Run install-startup.ps1 as Administrator
4. Restart computer

USAGE:
- Start: Double-click start.bat
- Stop: Double-click stop.bat
- Restart: Double-click restart.bat
- Status: Double-click status.bat

NETWORK ACCESS:
- Local machine: http://localhost or http://invoice.zeric.com
- Other devices: http://[SERVER-IP]
  (Replace [SERVER-IP] with the IP shown in setup)

FILE STORAGE:
- PDFs: ./storage/pdf/
- Excel: ./storage/excel/
- Database: ./database/invoices.db
